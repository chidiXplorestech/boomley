# Boomley

Boomley is a signal-driven product company. We notice recurring friction in everyday life and technology, investigate what matters, and build when something deserves to exist.

## Website

This repository contains the public Boomley website.

### Stack

- Astro
- TypeScript
- GSAP / ScrollTrigger / SplitText
- Modern CSS

### Development

```bash
npm install
npm run dev
```

### Build

```bash
npm run build
```

The production site is designed for Netlify.
